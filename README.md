# இலவச இணைய மாதிரித் தேர்வு – DECGC மயிலாடுதுறை & திருவாரூர்

TNPSC Group 1 · Group 2/2A · Group 4 · SSC · RRB · IBPS · IBPS RRB · SBI – இலவச இணைய மாதிரித் தேர்வுகள்.
Next.js + PostgreSQL (Neon), Vercel-இல் இயங்கும்.

## வசதிகள்
- **தேர்வுப் பிரிவு tabs** – ஒவ்வொரு தேர்வும் ஒரு பிரிவு (category) மற்றும் வகை (தினசரி / முழு மாதிரித் தேர்வு) கொண்டது.
- **மதிப்பெண் முறை ஒவ்வொரு தேர்வுக்கும்** – சரிக்கு மதிப்பெண், Negative marking, விடுபட்டால் குறைப்பு (TNPSC), E "விடை தெரியவில்லை".
  பிரிவு தேர்வு செய்தால் இயல்புநிலை மதிப்புகள் தானாக வரும் (TNPSC 1.5/0/E; SSC 2/−0.5; RRB 1/−⅓; வங்கி 1/−0.25).
- **5 விருப்ப வினாக்கள்** (வங்கித் தேர்வுகள்) – Excel-இல் `en_E` / `ta_E` நெடுவரிசை.
- **தினசரித் தேர்வுகள் + வாராந்திரப் பகுப்பாய்வு** (`/weekly?c=SSC`) – வாரத் தரவரிசை, பகுதி வாரித் துல்லியம், கடினமான வினாக்கள்,
  WhatsApp சுருக்கம், CSV.
- **முழுத் தேர்வுப் பகுப்பாய்வு** (`/analysis/<id>`) – சராசரி/இடைநிலை/அதிகபட்சம், மதிப்பெண் பரவல், பகுதி & மாவட்ட ஒப்பீடு,
  முதல் 10 / மாவட்ட முதல் 5, வினா வாரியான பகுப்பாய்வு (சரி %, விருப்பப் பரவல், கடினத்தன்மை, Discrimination,
  ⚑ விடைக்குறிப்பைச் சரிபார்க்க வேண்டியவை), தேர்வருக்குத் தனிப்பட்ட Percentile & பகுதி ஒப்பீடு.
- **ஆசிரியர் உள்நுழைவு** (`/faculty`) – Admin உருவாக்கும் கணக்கு; Excel பதிவேற்றம் → Admin ஒப்புதல் (`/admin/submissions`)
  → புதிய தேர்வாக உருவாகும்; நிராகரித்தால் காரணம் ஆசிரியருக்குத் தெரியும்.

## Environment variables
`DATABASE_URL` (Neon), `ADMIN_PASSWORD`, `SESSION_SECRET`. அட்டவணைகள் / புதிய நெடுவரிசைகள் தானாக உருவாகும் (பழைய தரவு பாதுகாப்பாக இருக்கும்).

## வினா Excel
`qno, section, en_question, en_A … en_D, [en_E], ta_question, ta_A … ta_D, [ta_E], answer`
section: TNPSC – `தமிழ்` / `GS` / `APT`; பிற தேர்வுகள் – `Reasoning`, `Quant`, `English`, `GA`, `Computer` போன்றவை.
பொருத்துக அட்டவணை வரிசை: `a. மொகஞ்சதாரோ | 1. கப்பல் துறைமுகம்`.
